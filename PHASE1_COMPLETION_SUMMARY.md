## 🚀 Следующие шаги для внедрения

### Шаг 1: Установить зависимости
```bash
cd backend
pip install -r requirements.txt
```

### Шаг 2: Обновить токен бота (КРИТИЧНО!)
1. Отозвать старый токен через [@BotFather](https://t.me/BotFather): `/mybots` → Bot Settings → Revoke token
2. Создать новый токен: `/newbot`
3. Обновить `backend/.env`:
   ```env
   TELEGRAM_BOT_TOKEN=your_new_bot_token_here
   ```

### Шаг 3: Интегрировать в server.py

Следуйте инструкциям из файлов:
1. **NOTIFICATIONS_INTEGRATION_GUIDE.md** — добавить импорты, API endpoints, интегрировать в существующие endpoints
2. **LIVE_STATUS_INTEGRATION_GUIDE.md** — обновить endpoints старта/завершения тренировок
3. **EXERCISE_HISTORY_INTEGRATION_GUIDE.md** — добавить API endpoint истории

### Шаг 4: Создать индексы БД

Добавить в `backend/seed.py` в функцию `ensure_indexes()`:
```python
# Индексы для системы уведомлений
await db.notification_settings.create_index("user_telegram_id", unique=True)
await db.notification_log.create_index([("user_telegram_id", 1), ("sent_at", -1)])
await db.notification_log.create_index("sent_at")
```

### Шаг 5: Тестирование

**Тест 1: Telegram Bot работает**
```bash
curl -X POST http://localhost:8000/api/notifications/test \
  -H "Authorization: Bearer YOUR_TOKEN"
```
Должно прийти сообщение в Telegram.

**Тест 2: Scheduler запущен**
```bash
curl http://localhost:8000/api/notifications/scheduler-status \
  -H "Authorization: Bearer YOUR_TOKEN"
```
Должны быть 4 задачи.

**Тест 3: Live-статусы обновляются**
- Запустить тренировку → проверить что статус = `on_workout`
- Завершить тренировку → проверить что статус = `completed`
- Открыть страницу тренера → должны быть цветные бейджи

**Тест 4: История весов**
```bash
curl "http://localhost:8000/api/exercises/bench-press/history/123456" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
Должен вернуться JSON с историей.
