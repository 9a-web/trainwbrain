# Реализация функционала суперсетов

## Обзор
Добавлена полная поддержка суперсетов — группировка упражнений без отдыха между ними, с возможностью задать отдых после завершения всей группы.

## Backend изменения

### 1. Модели (backend/models.py)

#### ProgramExercise
Добавлены поля для поддержки суперсетов:
```python
superset_id: Optional[str] = None              # ID группы суперсета (напр. "ss_1")
superset_order: Optional[int] = None           # порядок внутри суперсета (0, 1, 2...)
rest_after_superset: Optional[int] = None      # отдых после всех упражнений суперсета (секунды)
```

#### SessionExercise
Те же поля добавлены для сессий:
```python
superset_id: Optional[str] = None
superset_order: Optional[int] = None
rest_after_superset: Optional[int] = None
```

### 2. API (backend/server.py)

#### PlanExerciseReq
Расширен для принятия данных суперсета:
```python
superset_id: Optional[str] = None
superset_order: Optional[int] = None
rest_after_superset: Optional[int] = None
```

#### _normalize_plan_exercise
Функция обновлена для сохранения полей суперсета при создании/редактировании упражнения.

## Логика работы

### Создание суперсета:
1. Тренер нажимает "Суперсет" в редакторе плана
2. Создается первое упражнение с:
   - `superset_id = "ss_{timestamp}"`
   - `superset_order = 0`
   - `rest_after_superset = 120` (по умолчанию)
3. Визуально отображается в рамке с меткой "Суперсет"

### Добавление упражнения в суперсет:
1. Тренер нажимает "Добавить в суперсет"
2. Создается упражнение с тем же `superset_id`
3. `superset_order` устанавливается как `max + 1`
4. Упражнение добавляется в группу

### Редактирование упражнения в суперсете:
1. При открытии модалки редактирования определяется `isSuperset`
2. Показывается поле "Отдых после суперсета"
3. При сохранении поля суперсета сохраняются

### Разбить суперсет:
1. Тренер нажимает "Разбить суперсет"
2. Для всех упражнений группы:
   - `superset_id = null`
   - `superset_order = null`
   - `rest_after_superset = null`
3. Упражнения становятся обычными

### Отображение в тренировке:
1. Упражнения группируются по `superset_id`
2. Внутри группы сортируются по `superset_order`
3. Между упражнениями показывается индикатор "Без отдыха ↓"
4. После последнего упражнения показывается отдых

## Дизайн

### Цветовая схема:
- Основной цвет рамки: `#3B82F6` (синий)
- Вариации для разных суперсетов: 6 цветов
- Полупрозрачный фон: `rgba(59, 130, 246, 0.08)`

### Буквенные индикаторы:
- A, B, C, D, E, F для упражнений в суперсете
- Белый текст на цветном круге
- Размер: 28x28px

### Индикатор "Без отдыха":
- Вертикальная линия (2px)
- Текст заглавными буквами
- Цвет: rgba(255, 255, 255, 0.4)
