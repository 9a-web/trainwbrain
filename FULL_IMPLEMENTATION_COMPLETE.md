## 🚀 Как запустить

### Шаг 1: Клонировать репозиторий

```bash
cd C:\Users\79871\Desktop\TrainWBrain-v.1-main
```

### Шаг 2: Настроить Backend

```bash
cd backend

# Установить зависимости
pip install -r requirements.txt

# Создать .env файл (скопировать из .env.example)
copy .env.example .env

# Отредактировать .env:
# - MONGO_URL=mongodb://localhost:27017
# - DB_NAME=trainwbrain
# - TELEGRAM_BOT_TOKEN=your_new_bot_token
# - GOOGLE_CLIENT_ID=your_google_client_id (опционально)
# - GOOGLE_CLIENT_SECRET=your_google_client_secret (опционально)

# Запустить MongoDB (если не запущен)
# mongod --dbpath C:\data\db

# Загрузить seed data (создать индексы и упражнения)
python seed.py

# Запустить сервер
python server.py
```

Backend будет доступен на `http://localhost:8001`

### Шаг 3: Настроить Frontend

```bash
cd ../frontend

# Установить зависимости (используем yarn)
yarn install

# Создать .env файл
copy .env.example .env

# Отредактировать .env:
# REACT_APP_BACKEND_URL=http://localhost:8001

# Запустить dev-сервер
yarn start
```

Frontend будет доступен на `http://localhost:3000`

### Шаг 4: Открыть в браузере

Перейти на `http://localhost:3000` — приложение готово к использованию!

### Как собирать метрики

#### 1. % клиентов с отчётами
```javascript
// MongoDB Aggregation
db.daily_reports.aggregate([
  { $match: { date: { $gte: ISODate("2026-09-01") } } },
  { $group: {
      _id: "$athlete_telegram_id",
      reports_count: { $sum: 1 }
  }},
  { $lookup: {
      from: "users",
      localField: "_id",
      foreignField: "telegram_id",
      as: "user"
  }},
  { $project: {
      user_id: "$_id",
      reports_count: 1,
      has_reports: { $gte: ["$reports_count", 1] }
  }}
])
```

#### 2. Время тренера на клиента
```javascript
// Логировать каждое действие тренера
await db.user_actions.insertOne({
  user_id: coach_telegram_id,
  action: "view_client_profile",
  client_id: athlete_telegram_id,
  timestamp: new Date(),
  duration_seconds: 45
});
```

#### 3. Retention клиентов
```javascript
// Когорта пользователей, зарегистрированных в сентябре
db.users.aggregate([
  { $match: { created_at: { $gte: ISODate("2026-09-01"), $lt: ISODate("2026-10-01") } } },
  { $lookup: {
      from: "workout_sessions",
      localField: "telegram_id",
      foreignField: "athlete_telegram_id",
      as: "sessions"
  }},
  { $addFields: {
      last_session: { $max: "$sessions.started_at" },
      days_since_registration: { $dateDiff: {
          startDate: "$created_at",
          endDate: new Date(),
          unit: "day"
      }}
  }},
  { $project: {
      retained_30d: { $gte: ["$days_since_registration", 30] }
  }}
])
```

### Phase 2.1: Аналитика (2-3 недели)

#### 🎯 Статистика по мышечным группам
- **Проблема:** нет визуализации дисбаланса нагрузки
- **Решение:** карта нагрузки по мышцам за период
- **Реализация:**
  - Добавить поля `muscle_groups` и `secondary_groups` в `Exercise`
  - API endpoint `GET /api/stats/{athlete_tg}/muscle-groups?period=week|month|all`
  - Radial chart и bar chart для визуализации
- **Эффект:** тренер видит перекосы в программе и корректирует

#### 📈 Прогноз прогресса
- **Проблема:** клиент не знает когда достигнет цели
- **Решение:** ML-модель для прогноза 1RM через N недель
- **Реализация:**
  - Linear regression на истории весов
  - Экстраполяция на будущее
  - Визуализация "Вы достигнете 100 кг через 6 недель"
